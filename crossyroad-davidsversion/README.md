This game is inspired on the popular "Crossy Road". The mechanics are basically the same, you move using arrows or wasd on a keyboard, or by sliding on mobile. The unique aspects of my personal version, is that it has two added game modes: hard and extreme. The hard version is based on a red world with 1.5x the obstacle speed of normal mode and an increased playable screen of 9 columns to 13 coplumns. The cars are also turned to race cards and the river has a added feature,  flowing animations, both to emphasize the increased speed. The eagle is turned red aswell. The extreme mode is based on a purple apocalyptic alien-like world. It has meteors falling from the sky, and instead of an eagle that catches you if the palyer is too slow, it has an alien following you at all times, with it staying behind if the player goes fast, rewarding speediness. The speed of obstacles increases by 2, and the playable columns increase to 19. All modes follow the strandard "harder as you go" style of crossy road, with the full difficulty unlocked after row 180. Another unique aspect is that I used my Honduran culture to inspire 3 extra unique characters related to my culture, all with their name and description. To play the game, you first choose your character, then select the difficulty, play until you die, and then a "game over" screen appears where you can play again or go back to sslecting the difficulty, from which you can then go to the character selection screen. All game modes have there own score tracker. The tools I used was VS code with claude code implemented within, my strategy was to send instructions too build the general game. Surprisingly, it got it almost perfect in a single prompt, then I made minor fixes, then I added hard mode and then extreme mode, all with my unique sepcifications and tried the game in each mode to make necessary changes. Then I added the characters, again with unique specifications. Lastly I added it to my personal portfolio website. An important note is that I started fresh from 0, without resuming from the in class experiment. I choose this because what I ended up with in the class experiment was bad. Nothing is known to be broken or unfinished, the game works on mobile or on computers.
